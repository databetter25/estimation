## 시뮬레이션 엔진

- 모든 계산은 여러분의 브라우저(Web Worker) 안에서 실행된다. 서버로 보내는 데이터는 없고, 쿠키도 쓰지 않는다.
- 난수는 시드 고정 생성기 xoshiro128\*\*를 쓴다. 32비트 정수 연산만 쓰므로 시드와 설정이 같으면 같은 균등난수 수열이 나온다. 정규난수는 Marsaglia 극좌표법으로 만든다.
- 한 번 반복할 때 표본 하나를 뽑고, **같은 표본**으로 모든 추정량을 계산한다(공통 난수). 추정량 간 비교가 공정해진다.
- 분위수는 R type 7(NumPy `linear`) 정의를 쓴다. 절사평균은 양쪽에서 $\lfloor 0.1n \rfloor$개씩 버린다.
- 표의 분산은 $B$로 나눈 값이다. 그래서 분산 + 편향² = MSE가 정확히 성립한다.
- 엔진은 단위 테스트로 검증한다. 이론식이 있는 모든 추정량의 평균과 분산이 4만 회 반복에서 이론값 ±3 몬테카를로 표준오차 안에 들어와야 통과한다.

## 원천 자료 정정

이 사이트는 시뮬레이션 설계안과 개념 해설 두 편을 바탕으로 만들었다. 20만 회 몬테카를로 재검증 결과, 설계안 지표 표의 일부 수치를 바로잡았다.

| 추정량 | 원천 분산 / MSE | 정정 분산 / MSE |
| --- | --- | --- |
| 중앙범위 ($n=25$) | 0.32 / 0.32 | 0.533 / 0.533 |
| $\hat\sigma^2_{\mathrm{IQR}}$ ($n=25$) | 평균 4.03, 2.15 / 2.15 | 평균 3.76, 3.13 / 3.18 |
| $\frac{n+1}{n}X_{(n)}$ ($n=20$) | 0.02 / 0.02 | 0.227 / 0.227 |
| $X_{(n)}$ | 0.02 / 0.25 | 0.206 / 0.433 |
| $2\bar X$ | 0.17 / 0.17 | 1.667 / 1.667 |

그 밖에 다음을 정리했다.

- 표기 통일: $S^2$는 분모 $n-1$인 불편 표본분산, $\hat\sigma^2$는 분모 $n$인 MLE.
- 용어 통일: 처음 나올 때 "한글(영문, 약어)"로 쓴다. 예: 최대가능도추정법(Maximum Likelihood Estimation, MLE).
- "소표본에서 $\hat\sigma^2$의 MSE가 더 작다" → 정규분포에서는 **모든 $n$에서** 더 작고, $n$이 커지면 차이가 줄어든다.
